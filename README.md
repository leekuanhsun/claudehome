# 每月存錢計畫

一個純前端的預算與存款規劃工具，給一般上班族每月記帳、看見還能存多少錢。

- 每月實領薪水扣掉固定貸款、生活費預算、朋友聚會預算、信用卡分期，算出本月可分配金額。
- 每天記支出，看當日與當月生活費用到哪裡。
- 日記是獨立分頁：選心情、寫內容、最多 4 張照片、可附上位置，並在時間軸依月份查看。
- 記帳的細項會依類別變化：選「餐飲」顯示早餐、午餐、晚餐、下午茶；選「交通」顯示保養、加油、車票。每個類別都可以自己新增細項，自訂的可以用 × 移除。
- 每筆支出可選餐別（早餐、午餐、晚餐、下午茶，可複選）、附上最多 3 張照片、寫心得，並可選擇附上目前位置。
- 信用卡分期期間與分期結束後，分別估算每月可存金額，以及未來 12 個月的存款。
- 支出可匯出 CSV（已防止試算表公式注入）。
- 可加到手機主畫面，離線也能開啟。

資料只存在瀏覽器的 localStorage，不會上傳到任何伺服器。

## 使用方式

直接開啟 `index.html` 即可，或用本地伺服器（Service Worker 需要 http 或 https）：

```bash
npm start   # 在 http://localhost:8000 開啟
```

## 計算方式

```
工作日生活費預算 = 每月工作日 × 每日生活費上限
本月可分配金額   = 實領薪水 − 固定貸款 − 生活費預算 − 朋友聚會預算 − 信用卡分期月付
```

- **第 1 階段（分期中）**：每月存下「本月可分配金額」（負數時視為 0）。
- **第 2 階段（分期結束後）**：每月存下原本的分期月付金額，其餘作為彈性預算。
- **分期月數** = `ceil(剩餘本金 ÷ 月付)`。
- **未來 12 個月估算** = 分期期間每月存第 1 階段金額，之後每月存第 2 階段金額。
- 信用卡剩餘本金為 0 時，視為已繳清，不再扣除月付金額。
- 未計入信用卡分期利息。

## 多裝置同步（Supabase）

同一個網址可以在 iPhone、iPad、Mac、Windows 上使用，登入同一個帳號就會同步。

1. 到 https://supabase.com 建立專案（免費方案）。
2. 在 **SQL Editor** 貼上 `supabase/schema.sql` 的內容並執行一次。
3. 在 **Authentication → Users** 按 **Add user**，輸入自己的電子郵件與密碼（勾選自動確認）。
4. 在 **Project Settings → API** 複製 **Project URL**，填入 `supabase-config.js` 的 `url`。
5. 在任一裝置的設定頁登入，之後資料會自動同步。

- `anonKey` 是 publishable 金鑰，可以公開放在網頁上；資料安全靠 `schema.sql` 的 RLS 規則，每位使用者只能讀寫自己的資料。
- 同步的合併規則在 `calc.js` 的 `mergeDocs`，每次儲存後約 1.5 秒同步一次。
- 未登入或未設定時，應用程式仍可在本機使用。
- 免費專案一週沒有任何人使用會被暫停；平常使用就不會。

### 新增使用者與帳號安全
- **管理者新增使用者**（不開放註冊）：到 Supabase 的 **Authentication → Users → Add user**，輸入對方的電子郵件與密碼，勾選 **Auto Confirm User**。
- **讓別人自行註冊**：登入頁的「沒有帳號？註冊新帳號」可以註冊。這需要在 **Authentication → Sign In / Providers** 開啟 **Allow new users to sign up**。開啟後任何知道網址的人都能註冊，但註冊後只能看到自己的空白資料。
- **不想讓陌生人註冊**：關閉 **Allow new users to sign up**，只用 Add user 建立帳號；登入頁的註冊會顯示「目前不開放註冊」。
- **同一帳號多位使用者**：登入後會到「誰在用？」頁，像 Netflix 一樣選擇使用者，不需要密碼。每位使用者的記帳與日記資料分開，但都存在同一個帳號的雲端資料裡。可按「+ 新增使用者」建立，設定頁也能按「切換使用者」。舊資料會歸到「我」這位使用者。
- **切換帳號**：設定頁按「登出／切換帳號」，會清除這台裝置上的記帳資料（雲端的資料不會刪除），再到登入頁登入其他帳號。
- 網站沒有登入就只會看到登入頁，登出時會清除這台裝置上的記帳資料。
- 登入頁會列出這台裝置上登入過的帳號（只記電子郵件，不記密碼）。點頭像輸入密碼即可登入；「新增使用者」可以登入其他帳號或註冊。

## 注意事項

- 計算結果只是估算，未計入利息、獎金、保險扣款等變動項目。
- 未登入雲端同步時，清除瀏覽器資料或換裝置，記錄會消失；登入後資料會保存在雲端。
- 照片與所有資料都會存在 Supabase 的同一列資料中，單筆資料受 Supabase 的大小限制。
- 照片會縮小後以 base64 存在瀏覽器的 localStorage，容量通常約 5MB。照片多了之後可能無法再儲存，屆時會看到「無法儲存資料」的提示。
- 位置需要瀏覽器授權，且只在網站以 https 或 localhost 開啟時才能使用。
