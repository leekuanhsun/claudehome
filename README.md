# 每月存錢計畫

一個純前端的預算與存款規劃工具，給一般上班族每月記帳、看見還能存多少錢。

- 每月實領薪水扣掉固定貸款、生活費預算、朋友聚會預算、信用卡分期，算出本月可分配金額。
- 每天記支出，看當日與當月生活費用到哪裡。
- 日記是獨立分頁：選心情、寫內容、最多 4 張照片、可附上位置，並在時間軸依月份查看。
- 記帳的細項會依類別變化：選「餐飲」顯示早餐、午餐、晚餐、下午茶；選「交通」顯示保養、加油、車票。每個類別都可以自己新增細項，自訂的可以用 × 移除。
- 每筆支出可選餐別（早餐、午餐、晚餐、下午茶，可複選）、附上最多 3 張照片、寫心得，並可選擇附上目前位置。
- 信用卡分期期間與分期結束後，分別估算每月可存金額，以及未來 12 個月的存款。
- 支出可匯出 CSV（已防止試算表公式注入）。
- 可加到手機主畫面，離線也能開啟。

資料只存在瀏覽器的 localStorage，不會上傳到任何伺服器。

## 使用方式

直接開啟 `index.html` 即可，或用本地伺服器（Service Worker 需要 http 或 https）：

```bash
npm start   # 在 http://localhost:8000 開啟
```

## 頁面

| 頁面 | 檔案 | 內容 |
| --- | --- | --- |
| 總覽 | `index.html` | 本月可分配金額、各項預算、今日與本月進度、存錢路線摘要 |
| 記帳 | `expense.html` | 新增支出、快速金額、當日紀錄 |

| 明細 | `history.html` | 月份切換、生活費與聚會進度、分類統計、支出列表、匯出 CSV |

各頁面頂部有導覽列（手機版改為底部導覽列），頁面內也有連結可跳到相關頁面。

## 計算方式

```
工作日生活費預算 = 每月工作日 × 每日生活費上限
本月可分配金額   = 實領薪水 − 固定貸款 − 生活費預算 − 朋友聚會預算 − 信用卡分期月付
```

- **第 1 階段（分期中）**：每月存下「本月可分配金額」（負數時視為 0）。
- **第 2 階段（分期結束後）**：每月存下原本的分期月付金額，其餘作為彈性預算。
- **分期月數** = `ceil(剩餘本金 ÷ 月付)`。
- **未來 12 個月估算** = 分期期間每月存第 1 階段金額，之後每月存第 2 階段金額。
- 信用卡剩餘本金為 0 時，視為已繳清，不再扣除月付金額。
- 未計入信用卡分期利息。

## 雲端同步（手機與電腦共用資料）

資料預設只存在這台裝置。要讓手機與電腦看到同一份資料，需要設定一次 Supabase（免費方案）：

1. 到 https://supabase.com 建立專案。
2. 在專案的 **SQL Editor** 貼上 `supabase/schema.sql` 的內容並執行。
3. 在 **Authentication → URL Configuration** 設定：
   - Site URL：`https://leekuanhsun.github.io/claudehome/`
   - Redirect URLs：加入同一個網址
4. 在 **Project Settings → API** 複製 **Project URL** 與 **anon public** 金鑰，填入 `supabase-config.js`。
5. 打開設定頁，在「雲端同步」輸入 email 寄送登入連結，點信件裡的連結即可。

之後在任一台裝置登入，資料就會和其他裝置同步。未登入或未設定時，應用程式仍可在本機使用。

- 同步的合併規則在 `calc.js` 的 `mergeDocs`：同一筆取較新的版本，刪除會同步到其他裝置。
- 所有資料（含照片）會存在 Supabase 的同一列資料中，每位使用者只能讀寫自己的資料（由 RLS 規則保證）。
- 免費方案的登入信件有寄送數量限制，短時間內多次登入可能會收不到信。

## 注意事項

- 計算結果只是估算，未計入利息、獎金、保險扣款等變動項目。
- 未登入雲端同步時，清除瀏覽器資料或換裝置，記錄會消失；登入後資料會保存在雲端。
- 照片會縮小後以 base64 存在瀏覽器的 localStorage，容量通常約 5MB。照片多了之後可能無法再儲存，屆時會看到「無法儲存資料」的提示。
- 位置需要瀏覽器授權，且只在網站以 https 或 localhost 開啟時才能使用。
